# Wallpaper Rotator

A simple Python script for Windows that procedurally generates a unique
wallpaper on every script run.

## Features

* **Uses layered sine and consine waves to generate mountains.**
* **Some of the themes are Anime-inspired colors.**
* **The script renders multi-stop sky gradients, twinkling stars, and glowing mist layers between mountains.**

## Tech Stack

* **Python 3**
* **Pillow**
* **'ctypes & os'**
* **'math' & 'random'**

## Setup & Installation

### 1. Clone the Repo
```bash
git clone https://github.com/dakiddo-Eri/Wallpaper-Auto-Rotator
cd Wallpaper-Auto-Rotator
```
### 2. Install Dependencies
Make sure you have Python3 isntalled first
```bash
pip3 install pillow
```

### 3. Run ze script
```bash
python3 main.py
```
*(Note: if your monitor isnt't `1920x1080`, update the thing at top of the `main.py` file)
